== Description ==  

**Bulk Delete Comments** is a powerful WordPress plugin designed to help you efficiently manage and clean up comments on your site. Whether you need to **delete all comments** at once or target specific comment types like spam, unapproved, or trash, this plugin provides an easy and effective solution.

**Key Features:**  

- **Delete All Comments:** Remove all comments on your website in one click.  
- **Delete Comments by Type:** Quickly delete spam, approved, unapproved, and trash comments.  
- **Delete Comments by Post:** Choose a specific post and remove all associated comments.  
- **Delete Unapproved Comments by Category:** Clean up unapproved comments within specific categories.  
- **Hide Comments Globally:** Disable or hide all comments site-wide without deleting them.  

This plugin is perfect for bloggers, website owners, and administrators who want to keep their comment section clean and organized.  

**Plugin Options Location:**  
You can find all plugin options in your **WordPress Dashboard** under:  
**Settings → Bulk Delete Comments**  

**How It Works:**  

1. Install and activate the plugin.  
2. Go to **Settings → Bulk Delete Comments** in your WordPress dashboard.  
3. Select the action you want to perform: **delete all comments**, clean by type, or target posts/categories.  
4. Click the “Delete” button, and the plugin will clean up your comments instantly.  

== Installation ==  

1. Upload the plugin files to the `/wp-content/plugins/bulk-delete-comments` directory, or install the plugin through the WordPress plugins screen directly.  
2. Activate the plugin through the 'Plugins' screen in WordPress.  
3. Navigate to **Settings → Bulk Delete Comments** in your WordPress dashboard.  
4. Use the options to bulk delete comments or filter them by type, post, or category.  

== Frequently Asked Questions ==  

= Where can I find the plugin options? =  
You can access the plugin options from your WordPress Dashboard under **Settings → Bulk Delete Comments**.  

= Will this plugin permanently delete comments? =  
Yes, once comments are deleted, they cannot be restored. Be sure to back up your database if needed.  

= Can I delete comments only from a specific post? =  
Yes, you can target specific posts and delete all comments associated with them.  

= Is it possible to hide comments without deleting them? =  
Yes, the plugin includes an option to globally hide comments across your site without removing them.  

= Does this plugin delete spam comments? =  
Yes, you can choose to delete spam comments specifically.  

= Does this plugin back up comments in any other table? =  
No, it does not.
